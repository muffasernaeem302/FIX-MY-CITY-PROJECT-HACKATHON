# REST API Surface (High-Level)

| Method | Path                               | Auth          | Purpose                              |
|--------|------------------------------------|---------------|--------------------------------------|
| POST   | /api/auth/register                 | public        | Register citizen                     |
| POST   | /api/auth/login                    | public        | Login -> JWT                         |
| GET    | /api/auth/me                       | any           | Current user profile                 |
| GET    | /api/departments                   | any           | List departments                     |
| POST   | /api/incidents                     | citizen       | Create incident (multipart)          |
| GET    | /api/incidents                     | any           | List (citizen: own / admin: all)     |
| GET    | /api/incidents/{id}                | any           | Detail incl. AI + risk + images      |
| GET    | /api/incidents/mine                | citizen       | My reports                           |
| POST   | /api/uploads                       | any           | Generic image upload (returns URL)   |
| POST   | /api/ai/classify                   | any           | Classify an uploaded image           |
| POST   | /api/incidents/{id}/status         | admin         | Change status (validated)            |
| POST   | /api/incidents/{id}/assign         | admin         | Assign department                    |
| POST   | /api/incidents/{id}/repair         | admin         | Submit after-repair evidence         |
| POST   | /api/incidents/{id}/verify         | admin         | AI verify before/after               |
| GET    | /api/admin/metrics                 | admin         | Dashboard KPIs (real DB counts)      |
| GET    | /api/admin/priority-queue          | admin         | Top incidents by risk                |
| GET    | /api/admin/analytics/categories    | admin         | Category breakdown                   |
| GET    | /api/admin/analytics/trends        | admin         | Time-series for charts               |
| GET    | /api/admin/duplicates              | admin         | Duplicate groups                     |
| GET    | /api/notifications                 | any           | My notifications                     |

## Response Envelopes

**Success:**
```json
{ "ok": true, "data": ... }
```

**Error:**
```json
{ "ok": false, "error": { "code": "...", "message": "...", "details": {...}? } }
```

Full request/response schemas will be in `docs/01-api.md` and auto-generated by FastAPI at `/docs`.
